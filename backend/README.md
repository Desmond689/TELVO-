# Telvo Backend API

## Overview
Telvo backend API built with Node.js, Express, and Firebase.

## Features
- 🔐 Authentication (Phone OTP, Google, Apple, Facebook)
- 👤 User Management
- 📋 Job Posting & Management
- 💳 Payment Processing (Cash, MTN MoMo, Orange Money)
- 💬 Real-time Chat
- ⭐ Reviews & Ratings
- 🔔 Push Notifications
- 🤖 AI Features
- 🛡️ Admin Panel
- 📊 Analytics

## Tech Stack
- Node.js + Express
- Firebase (Auth, Firestore, Storage)
- Redis (Caching)
- Bull (Background Jobs)
- Winston (Logging)
- JWT (Authentication)
